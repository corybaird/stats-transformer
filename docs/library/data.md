# Repository Data Directory Guide & Example Catalog

This document details the organization of the `data/` directory in `stats-transformer`, highlighting the tracked repository datasets used for automated testing, academic replications, and model demonstrations. The separately packaged default dataset lives under `src/stats_transformer/data/`.

---

## 1. Directory Overview & Git Tracking

The `data/` directory separates tracked example datasets from local pipeline outputs and raw ingestion folders.

```text
data/
├── examples/                    # Repository datasets for tests & examples
│   ├── academic/                # Replication datasets (Nakamura-Steinsson, Bauer-Swanson)
│   ├── timeseries/              # Time-series textbook datasets (Ghysels, Kilian)
│   ├── regression/              # Applied regression benchmarks (Longley, Grunfeld, Mroz)
│   ├── discrete/                # Binary classification datasets (Spector & Mazzeo Logit)
│   ├── matlab_examples/         # MATLAB benchmark workbooks
│   └── macrodb_gdp_inflation.parquet  # Repository copy of the default macro panel
├── raw/                         # Local/Ignored: Raw data downloads partitioned by frequency
├── final/                       # Local/Ignored: Standardized panel parquets generated by preprocessing
├── pipeline/                    # Local/Ignored: Intermediate stage parquets generated by Pipeline.run()
└── temp/                        # Local/Ignored: Transient temporary working files
```

### Git Tracking & Verification Policy

- **Tracked in Version Control**: The datasets listed in the table below are committed under `data/examples/`. The separately sourced `data/examples/academic/ghysels_2018/` directory is ignored and is not available in a clean checkout.
- **Packaged with the Library**: `src/stats_transformer/data/macrodb_gdp_inflation.parquet` is the packaged copy loaded by `load_example("macrodb_gdp_inflation")`. The repository-level `data/examples/` tree is excluded from the source distribution.
- **Ignored in Version Control**: Local pipeline intermediates (`data/pipeline/`), final panel outputs (`data/final/`), temporary working files (`data/temp/`), and external raw downloads (`data/raw/`) are ignored via `.gitignore` to prevent repository bloat.

## 3. Usage in Python API & YAML Pipeline

### 3.1 Programmatic Access via `load_example`

```python
from stats_transformer.data import list_examples, load_example

# List all available example datasets
print(list_examples())

# Load default macroeconomic panel for testing or modeling
df = load_example("macrodb_gdp_inflation")
```

### 3.2 YAML Pipeline Configuration (`params.yaml`)

```yaml
data:
  featurization:
    entity_column: country
    date_column: date
    period: quarterly
  datasets:
    - name: macro_data
      path: data/examples/timeseries/macrodata.csv
      frequency: Q
  merge:
    on:
      - country
      - date
    how: inner
```

## 4. Detailed Dataset Catalog

### 4.1 Macroeconomic Panel (`data/examples/macrodb_gdp_inflation.parquet`)
- **Description**: Default multi-country annual panel covering GDP and inflation indicators.
- **Primary Use**: Repository copy of the default panel. `stats_transformer.data.load_example("macrodb_gdp_inflation")` loads the packaged copy from `src/stats_transformer/data/`.

### 4.2 Academic Replication Datasets (`data/examples/academic/`)
- **Acosta, Brennan, & Jacobson (2024)**: High-frequency SOFR futures surprises and policy path indicators in `data/examples/academic/acosta_brennan_jacobson_2024/sofr_surprises.parquet.gzip`. Used in `src/examples/academic/acosta_brennan_jacobson_2024.py`.
- **Cieslak, Hansen, McMahon, & Xiao (2024)**: Policymakers' Uncertainty (PMU) text and market indicators in `data/examples/academic/cieslak_hansen_mcmahon_xiao_2024/pmu_data.parquet.gzip`. Used in `src/examples/academic/cieslak_hansen_mcmahon_xiao_2024.py`.
- **Shapiro, Sudhof, & Wilson (2022)**: High-frequency daily news sentiment series in `data/examples/academic/shapiro_sudhof_wilson_2022/news_sentiment.parquet.gzip`. Used in `src/examples/academic/shapiro_sudhof_wilson_2022.py`.
- **Lane (2025)**: Industrial policy loans and tariff data in `data/examples/academic/lane_2025/policy_loans.parquet.gzip` and `tariffs.parquet.gzip`. Used in `src/examples/academic/lane_2025.py`.
- **Miranda-Agrippino & Rey (2020)**: Published Global Factor reference series and model input panel in `data/examples/academic/miranda_agrippino_rey_2020/`. Used in `src/examples/academic/miranda_agrippino_rey_2020.py` and the dynamic-factor YAML configuration.
- **Coibion & Gorodnichenko (2012)**: FOMC Greenbook CPI forecast and backcast series in `data/examples/academic/coibion_gorodnichenko_2012/greenbook_forecast_errors.parquet.gzip`. Used in `src/examples/academic/coibion_gorodnichenko_2012.py`.
- **Nakamura & Steinsson (2018)**: High-frequency monetary policy surprise series in `data/examples/academic/nakamura_steinsson_2018/`, with a separate `synthetic_nakamura.csv` PCA fixture. Used in `src/examples/academic/nakamura_steinsson.py` and `nakamura_steinsson_pca.py`.
- **Bauer & Swanson (2023)**: Orthogonalized monetary surprise inputs in `data/examples/academic/bauer_swanson_2023/`, used in `src/examples/academic/bauer_swanson.py`.
- **Bauer, Bernanke, & Milstein (2023)**: Yield curve dataset in `data/examples/academic/bbm_2023/` used in `src/examples/academic/bauer_bernanke_milstein.py`.
- **Jarociński & Karadi (2020)**: FOMC-day fed funds futures, Treasury yield, and equity surprises in `data/examples/academic/jarocinski_karadi_2020/fomc_surprises.parquet.gzip`. Used in `src/examples/academic/jarocinski_karadi_2020.py`.

### 4.3 Time-Series Textbook Datasets (`data/examples/timeseries/`)
- **Ghysels & Marcellino (2018) Chapter 6 & 7**: Datasets for US monetary series, EU GDP growth, UK term structure, and US leading economic indicators in `data/examples/timeseries/ghysels_ch6/` and `ghysels_ch7/`.
- **Kilian & Lütkepohl (2017)**: Structural VAR and VECM demonstration series.

### 4.4 Regression Benchmark Datasets (`data/examples/regression/`)
- **Longley Dataset (1967)**: Highly collinear economic dataset used for OLS/Robust OLS testing in `src/examples/regression/longley.py`.
- **Grunfeld Panel Dataset (1958)**: Corporate investment panel dataset used for fixed-effects panel regression testing in `src/examples/regression/grunfeld.py`.
- **Mroz IV Dataset (1987)**: Female labor supply dataset used for 2SLS instrumental variables testing in `src/examples/regression/mroz_iv.py`.
- **Mincer Wage Dataset**: Cross-sectional wage data used for the robust OLS Mincer equation in `src/examples/regression/mincer_wage.py`.
- **Okun's Law Dataset**: Quarterly GDP growth and unemployment changes used in `src/examples/regression/okuns_law.py`.
- **Ghysels & Marcellino (2018), Chapters 1 & 2**: Regression, forecasting, misspecification, and diagnostics datasets under `data/examples/regression/ghysels_ch1/` and `ghysels_ch2/`.

### 4.5 Discrete Choice Datasets (`data/examples/discrete/`)
- **Spector & Mazzeo Logit Dataset (1980)**: Educational performance dataset used for binary Logit testing in `src/examples/discrete/spector_logit.py`.

### 4.6 MATLAB Benchmark Workbooks (`data/examples/matlab_examples/`)
- **Structural identification**: `ADRR2018_Data.xlsx`, `BQ1989_Data.xlsx`, and `Uhlig2005_Data.xlsx` support narrative, long-run, and sign-restriction examples.
- **Proxy SVAR and local projections**: `GK2015_Data.xlsx` and `JT2025_Data.xlsx` support external-instrument SVAR and LP-IV examples.
- **Reduced-form and structural VAR**: `SW2001_Data.xlsx` supports Stock-Watson VAR and SVEC examples.
